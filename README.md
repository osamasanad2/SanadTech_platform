# SANAD — سند

> **Digital · Engineering · Design**

SANAD is a Yemeni digital, engineering, and design company website. Built with pure HTML, CSS, and JavaScript — bilingual (Arabic / English), dark-themed, and fully responsive.

## Features

- Bilingual support (Arabic RTL / English LTR)
- Dark theme with modern UI
- GSAP animations (scroll-triggered, loader, typing effect)
- Interactive portfolio with modal viewer
- Services section with detail modals
- WhatsApp direct messaging integration
- Fully responsive design

## Tech Stack

- HTML5
- CSS3 (custom properties, flexbox, grid, animations)
- JavaScript (vanilla, ES6+)
- GSAP (ScrollTrigger, ScrollToPlugin)
- Font Awesome 6

## Folder Structure

```
sanad-website/

├── js/
```

## Usage

Open `index.html` directly in any modern browser — no build step required.
